# 유저 제안 대시보드 (유대시) 스킬

## 개요

유저들이 오늘의집 앱 내 '개선 제안' 기능을 통해 직접 남긴 의견 데이터베이스입니다.
기획/디자인 결정의 정성적 근거로 사용할 수 있습니다.

**데이터 출처**: [유대시: 유저 제안 대시보드](https://docs.google.com/spreadsheets/d/1VZl77JKS-Zw_muZJTk1EjENNOuBPL_J-xepg_kS96z8/edit)

---

## 언제 사용하나요

- PRD / 1pager의 "유저 Pain Point" 또는 "정성 데이터" 섹션 작성 시
- 특정 기능(검색, 콘텐츠 탭, 추천, 배송, 리뷰 등)에 대한 유저 불만 파악 시
- 기획 결정에 VOC(Voice of Customer) 근거가 필요할 때
- UX 리서치 가설 수립 전 사전 탐색 시
- 팀 설득 자료에 실제 유저 인용문이 필요할 때

---

## 데이터 구조

### 키워드 분류 체계

대분류(트랙/TF) → 중분류 → 소분류 3단계로 구성됩니다.

**Content TF**
- 콘텐츠: 업로드, 제작/편집, 콘텐츠 타입, 챌린지, 태그
- 크리에이터: 수익화 프로그램, 소통
- 뷰어: 상품/콘텐츠 발견, 상품 탐색, 콘텐츠 탐색, 저장/스크랩

**Commerce TF**
- 커머스 기획: 이벤트/기획전
- 커머스 서비스: 리뷰, 상품 카테고리, 가격, 브랜드, 나만의패키지
- 커머스 플랫폼: 쿠폰, 혜택, 주문/결제, 배송, 교환/환불/클레임, 포인트
- 브랜드사업: PB, 단독

**Search & Rec TF**
- 추천, 검색(기능), 검색

**기타**
- 사용성: OS, 신뢰도, 심미성
- 커뮤니티: 커뮤니티홈
- O2O: 오프라인 관련
- 소통: 앱 내 소통 기능

### 시트 구성
| 시트명 | 내용 |
|--------|------|
| 대시보드 | 기간별 키워드 빈도 차트 |
| 검색 | 키워드로 관련 의견 필터링 조회 |
| 키워드별 보기 | 대/중/소분류 필터 후 의견 목록 |
| 1. 키워드 분류 테이블 | 전체 키워드 분류 체계 |
| 2. 키워드 카운트 | 기간별 키워드 등장 빈도 |
| raw | 전체 원문 의견 데이터 |

## 사용 방법

### 1단계: 키워드 파악

조회하려는 기능/영역의 키워드를 아래 분류 체계에서 찾으세요.

예시:
- 콘텐츠 탭 몰입 개선 → `콘텐츠 탐색`, `콘텐츠 타입`, `추천`, `검색(기능)`
- 검색 개편 → `검색(기능)`, `검색`, `상품 탐색`
- 리뷰 기능 → `리뷰`, `신뢰도`

### 2단계: 데이터 조회

#### 방법 A — Google Sheets MCP 직접 조회 (권장)

> `mcp__google-workspace-mcp__read_sheet_values` 도구가 사용 가능한 경우 이 방법을 사용하세요.

**스프레드시트 ID**: `1VZl77JKS-Zw_muZJTk1EjENNOuBPL_J-xepg_kS96z8`

**조회 전략:**

1. **최신 의견 조회** — raw 시트는 최신순 정렬 (Row 2가 가장 최신)
   - 최근 500건: `raw!A1:C501`
   - 최근 1000건: `raw!A1:C1001`
   - 필요 시 더 넓은 범위 조회 가능

2. **키워드 분류 체계 확인** — 관련 키워드 파악 시
   - 범위: `1. 키워드 분류 테이블!B3:D100`
   - 대분류(트랙/TF) → 중분류 → 소분류 구조

3. **키워드 빈도 확인** — 트렌드 파악 시
   - 범위: `2. 키워드 카운트!A1:U100`

**조회 예시:**
```
read_sheet_values(
  spreadsheet_id: "1VZl77JKS-Zw_muZJTk1EjENNOuBPL_J-xepg_kS96z8",
  range_name: "raw!A1:C1001"
)
```

**데이터 필터링:**
- raw 시트에서 읽어온 데이터 중 '개선 의견' 컬럼(C열)에서 관련 키워드를 텍스트 매칭으로 필터링
- 여러 키워드를 OR 조건으로 검색하여 관련 의견을 최대한 수집
- 날짜 범위가 필요하면 '등록일 추출' 컬럼(B열) 기준으로 필터링

#### 방법 B — MCP 미연결 시 폴백 (대화형)

> Google Sheets MCP 도구를 사용할 수 없는 경우, 사용자에게 아래 옵션을 제안하세요.

사용자에게 다음과 같이 안내합니다:

```
현재 Google Sheets에 직접 연결할 수 없어서, 두 가지 방법으로 도와드릴 수 있어요:

1️⃣ **스킬 내 요약 데이터로 답변** — 2026년(1/1~11/26) 기준 키워드 빈도와 커머스 관련 VOC 패턴, 2025 Q4 기준 콘텐츠탭 관련 VOC 패턴 등
   요약된 데이터를 바탕으로 바로 답변드릴 수 있어요. 다만 최신 데이터는 반영되지 않아요.

2️⃣ **스프레드시트에서 직접 확인** — 최신 원본 데이터 조회
   아래 링크에서 키워드 검색이나 필터링으로 직접 확인할 수 있어요.
   - 🔎 검색 시트: https://docs.google.com/spreadsheets/d/1VZl77JKS-Zw_muZJTk1EjENNOuBPL_J-xepg_kS96z8/edit#gid=2101276496
   - 🔠 키워드별 보기: https://docs.google.com/spreadsheets/d/1VZl77JKS-Zw_muZJTk1EjENNOuBPL_J-xepg_kS96z8/edit#gid=1569038008

어떤 방법으로 진행할까요?
```

- 사용자가 1️⃣을 선택하면: 아래 "빈도 높은 키워드", "콘텐츠탭 관련 주요 유저 의견", "커머스 관련 주요 유저 의견" 섹션의 요약 데이터를 활용하여 답변하되, **"이 데이터는 2026년 1월 1일~11월 26일 기준 스냅샷입니다"** (콘텐츠탭 의견은 **"2025 Q4 기준 스냅샷입니다"**) 라고 반드시 명시
- 사용자가 2️⃣를 선택하면: 스프레드시트 사용법을 간단히 안내 (검색 시트에서 키워드 입력 → 관련 의견 확인)

## 빈도 높은 키워드 (2026년 1/1~11/26 기준)

기간 내 의견 4,310건. "2. 키워드 카운트" 시트의 소분류별 키워드를 raw 원문에 대조해 센 건수 (한 의견이 여러 소분류에 잡힐 수 있음):

8. **오퍼월** 273건 (6.3%)
9. **이벤트/기획전** 255건 (5.9%)

## 콘텐츠탭 관련 주요 유저 의견 (요약)

콘텐츠탭 관련 작업 시 참고할 주요 VOC 패턴:

**발견/탐색 불편**
- 원하는 스타일/취향 콘텐츠 찾기 어려움
- 추천이 반복적이거나 비슷한 콘텐츠만 나옴
- 인스타그램처럼 취향 기반 피드 구성 요청

**콘텐츠 타입 구분**
- 협찬/광고 콘텐츠와 실제 후기 구분이 어려움
- 포토리뷰, 집들이, 노하우 등 타입별 분리 탐색 요청

**저장/스크랩**
- 스크랩 후 다시 찾기 어려움
- 위시리스트, 폴더 기능 요청

## 커머스 관련 주요 유저 의견 (요약)

쿠폰, 패키지 할인, 장바구니, 혜택 관련 작업 시 참고할 주요 VOC 패턴 (2026년 1/1~11/26 의견 기준):

**패키지 할인 (나만의패키지 84건)**
- 할인 폭이 개별 구매와 큰 차이가 없다고 느낌
  - "패키지 할인이 따지고보니 개별구매 할인 금액과 큰 차이가 없었음" (2026.09)
  - "무빙패스나 패키지 할인이 따로 따로 비교해보면 할인율이 크지 않는 게 아쉽다" (2026.11)
- 상품 조합을 만드는 과정이 복잡함
  - "패키지 상품 조합 만드는 부분에서 너무 복잡하고 자유도가 떨어지게 느껴져요. 자동 체크 되는 것도 불편해요." (2026.09)
- 구매 후 전체 취소, 상품 추가, 개별 가격 확인 요청
  - "패키지할인으로 구매한 후에 전체취소가 가능했으면 좋겠습니다 또는 패키지할인후 바로 추가하고싶은 상품이 있을때 패키지추가가 가능했으면 좋겠습니다" (2026.10)

**장바구니 (79건)**
- 장바구니에서 패키지 할인으로 바로 이어지길 원함
  - "장바구니에서 바로 패키지할인 추가하기가 있었으면 좋겠어요" (2026.08)
  - "장바구니에서 패키지 할인으로 넘어가는 부분에서 연동이 잘 안 된다고 느꼈어요." (2026.05)
- 쿠폰 적용가, 가격 인하를 장바구니에서 확인하고 싶어함
  - "쿠폰 적용했을때 가격이 장바구니에서 안보여서 불편함." (2026.03)
- 여러 상품을 사도 배송비가 각각 붙음
  - "여러 제품을 구매해도 배송비가 각각 나가서 비용이 훨씬 비싸지는 점이 아쉬워요!" (2026.02)

**쿠폰 (202건)**
- 쿠폰은 많은데 내가 쓸 수 있는 걸 찾기 어려움
  - "쿠폰 다운 관련 uiux 개선 한눈에 보기 어렵고 할인을 위해 쿠폰 서치하다가 피로함을 느껴 구매까지 닿지 않음" (2026.04)
  - "추가로 받을 수 있는 쿠폰,혜택이 쉽게 나와있으면 좋을거같아요" (2026.04)
- 첫 구매 쿠폰, 쿠폰 규모 확대 요청
  - "첫구매자를 위한 좀더큰 쿠폰이나 할인 혜택이 있으면 좋겠어요" (2026.09)
- 선착순 쿠폰의 남은 수량을 알 수 없음
  - "쿠폰마감이 시작과 동시에 됩니다. 수량표시라도 해주시면 좋을 것 같아요." (2026.03)

**혜택, 적립 (76건)**
- 예상 적립 포인트를 미리 알기 어려움
  - "결제 이후 예상 적립 포인트 정보가 명확히 표기되었으면 합니다" (2026.10)
- 결제 할인과 적립금을 함께 쓸 수 없음
  - "결제할인 이용시 적립금 사용이 안되는 점이 불편해요" (2026.11)

건수는 "2. 키워드 카운트" 시트의 분류별 키워드를 raw 원문에 대조해 센 값 (기간 내 의견 4,310건, 한 의견이 여러 분류에 잡힐 수 있음).

## 주의사항

- 데이터는 **앱 내 제안 기능**을 통해 수집된 것으로, 적극적 의견 표출 유저 편향 있음
- 침묵하는 다수(silent majority)의 의견은 별도 리서치로 보완 필요
- 정량 데이터(클릭률, 전환율 등)와 함께 삼각검증하여 활용 권장
- 최신 데이터 확인은 스프레드시트 직접 접근 권장
